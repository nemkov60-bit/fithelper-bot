# Фитнес-бот для Telegram

Бот помогает тренироваться: составляет программу под цель, показывает, какие группы мышц
тренируем сегодня, сколько подходов, повторов и отдыха, записывает результаты и следит за прогрессом.

## Что умеет

- **Анкета** — пол, возраст, цель (масса / сила / похудение / тонус), опыт, тренировок в неделю (2–5),
  где тренируешься (зал / дом); для девушек — учёт менструального цикла (по желанию).
- **Готовая программа на неделю** — сплит подбирается автоматически:
  2 дня — всё тело A/B; 3 дня — всё тело (новичок) или жим/тяга/ноги; 4 дня — верх/низ ×2;
  5 дней — жим/тяга/ноги + верх/низ. Подходы, повторы и отдых зависят от цели, опыта и возраста.
- **Для новичков** — стартовые веса для каждого упражнения (отдельно для мужчин и женщин),
  объяснение «как читать программу», тренажёры вместо сложных упражнений (без подтягиваний,
  брусьев и становой тяги), период адаптации: первые 2 недели — на подход меньше и лёгкие веса.
- **Пол** — для женщин акцент на ноги и ягодицы, шаг прибавки веса меньше (1.25 кг для верха тела),
  дома новичкам — отжимания с колен.
- **Возраст** — до 18 и 60+: без околомаксимальных весов (от 8 повторов), 60+ — тренажёры вместо
  тяжёлой штанги, не больше 3 подходов, отдых дольше; 40+ — длинная разминка и чуть больше отдыха.
- **Менструальный цикл** — бот считает день и фазу цикла и меняет тренировку:
  менструация — облегчённая (на подход меньше, отдых дольше, без повышения весов; можно выбрать
  обычную по самочувствию), после неё — время прибавлять веса, овуляция — акцент на разминку,
  за 5 дней до менструации — держим веса. Средняя длина цикла уточняется по отметкам «месячные начались».
- **«Тренировка на сегодня»** — группы мышц, упражнения, план `4×6–10, отдых 2 мин`, результаты прошлого раза.
- **Дневник подходов** — во время тренировки отправляешь `60 10` (вес и повторы) или `12` (только повторы);
  кнопка «Как прошлый подход», таймер отдыха с напоминанием.
- **Прогрессия нагрузки** — подсказка перед каждым упражнением: добавить вес, оставить или добить повторы.
- **Прогресс** — тренировки за неделю/месяц, выполнение плана, личные рекорды (с оценкой 1ПМ), история.
- **Вес тела и цели** — дневник веса, цель по весу тела и по рабочим весам в упражнениях с прогресс-баром.

- **Кнопка «📖 Техника»** — у каждого упражнения (в карточке тренировки, в плане дня и в «Моей программе»):
  понятное описание — подготовка, выполнение по шагам, дыхание, частые ошибки — и фото кадров.
  Тексты — в `exercise_technique.py`.
- **Админ-панель** (кнопка «🛠 Админ» или `/admin`, только для `ADMIN_ID`) — статистика бота и загрузка
  фото техники прямо через Telegram: группа мышц → упражнение → кадр → отправить фото. Бот показывает
  промт для генерации каждого кадра, сам переходит к следующему кадру, умеет удалять фото и хранить
  отдельную женскую версию. Быстрый способ — отправить фото с подписью `bench 1` (`bench 1 f` — женская
  версия). Фото хранятся в Telegram (в базе — только file_id), поэтому не занимают место на хостинге.
  Промты всех кадров — в [`IMAGE_PROMPTS.md`](IMAGE_PROMPTS.md); картинки можно также класть
  в `images/` как `bench_1.png`.

Пошаговая инструкция для GitHub + BotHost — в [`DEPLOY.md`](DEPLOY.md).

## Запуск на компьютере

```bash
pip install -r fitness_bot/requirements.txt
echo "FITNESS_BOT_TOKEN=123456:ABC..." > fitness_bot/.env   # токен от @BotFather
python fitness_bot/fitness_bot.py
```

Переменные окружения: `FITNESS_BOT_TOKEN` (или `BOT_TOKEN`) — токен, обязательно;
`ADMIN_ID` — Telegram ID администратора (можно несколько через запятую): админ-панель, загрузка фото,
`/backup` (копия базы);
`FITNESS_DATA_DIR` — папка для данных (по умолчанию `data/` рядом с ботом), `FITNESS_TZ` — часовой пояс
(по умолчанию `Europe/Moscow`), `FITNESS_IMAGES` — папка с картинками упражнений.

python -m unittest discover -s fitness_bot/tests
