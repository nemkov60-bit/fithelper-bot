# Картинки техники упражнений

Сюда кладутся сгенерированные иллюстрации. Имя файла: `<id упражнения>_<номер кадра>.<png|jpg|webp>`,
например `bench_1.png`, `bench_2.png`. Женская версия: `bench_1_f.png` (бот покажет её девушкам,
а если её нет — общую).

Промты для генерации — в `../IMAGE_PROMPTS.md`.
