# Фото техники упражнений

Проще всего загружать фото через бота: «🛠 Админ» → «📸 Фото упражнений».

Если класть файлы сюда: `<id упражнения>_<номер кадра>.<jpg|png|webp>` — мужская версия 👨
(например `bench_1.jpg`), `<id>_<кадр>_f.<jpg|png|webp>` — женская версия 👩 (`bench_1_f.jpg`).
Мужчины видят мужские фото, девушки — женские; если версии своего пола нет, показывается другая.

Промты для генерации — в `../IMAGE_PROMPTS_RU.md` (русский) и `../IMAGE_PROMPTS.md` (English).
