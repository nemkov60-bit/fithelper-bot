# Промты для иллюстраций упражнений

Для каждого упражнения — минимум два кадра: исходное и конечное положение (для сложных базовых — третий кадр с ключевой деталью или типичной ошибкой).

**Как пользоваться**

1. Скопируй промт в генератор изображений (Midjourney, DALL·E, Stable Diffusion, Kandinsky, Шедеврум).
2. Сохрани картинку в `fitness_bot/images/` с именем `<id>_<номер кадра>.png`, например `bench_1.png`.
3. Бот сам покажет картинки с подписями перед упражнением.

Единый стиль серии: `Clean instructional fitness illustration, flat vector style with soft shading, full body visible, plain light grey background, accurate human anatomy and joint angles, consistent character across the series, no text, no labels, no watermark, no logos, 4:3 aspect ratio`

Персонаж: `athletic man in a plain black t-shirt, grey shorts and white sneakers`. Для женской версии замени его на `athletic woman in a black sports top, grey leggings and white sneakers` и сохрани файлы с суффиксом `_f`, например `bench_1_f.png`, — их бот покажет девушкам.

Совет для Midjourney: добавь в конец `--ar 4:3 --style raw`, для серии — один и тот же `--seed`.
