# Запуск бота @FitHelperTop_bot на GitHub + BotHost

Схема простая: код лежит на **GitHub**, **BotHost** берёт его оттуда, устанавливает библиотеки
и держит бота запущенным круглосуточно. Компьютер для работы бота не нужен.

> ⚠️ Названия кнопок в панели BotHost могут немного отличаться от написанных здесь — интерфейс
> хостинга меняется. Смысл шагов везде одинаковый: подключить репозиторий → указать главный файл →
> добавить переменные → запустить.

---

## Что понадобится

| Что | Где взять |
|---|---|
| Токен бота | @BotFather → `/mybots` → **FitHelperTop_bot** → **API Token** |
| Твой Telegram ID (для команды `/backup`) | напиши боту @userinfobot — он пришлёт число `Id` |
| Аккаунт GitHub | github.com |
| Аккаунт BotHost | bothost.ru |

> 🔒 **Токен — это пароль от бота.** Никогда не загружай его на GitHub и не публикуй.
> Если токен случайно попал в открытый доступ: @BotFather → `/mybots` → бот → **API Token** →
> **Revoke current token** — старый перестанет работать, получишь новый.

## Шаг 1. Отдельный репозиторий для фитнес-бота на GitHub

Сейчас фитнес-бот лежит в папке `fitness_bot/` репозитория `stokpoisk`, а в корне этого репозитория —
другой бот (СтокПоиск) со своим `bot.py` и `requirements.txt`. Хостинги ищут главный файл и
`requirements.txt` в корне, поэтому надёжнее завести **отдельный репозиторий**, где файлы фитнес-бота
лежат сразу в корне.

### 1.1. Скачай файлы

1. Открой https://github.com/nemkov60-bit/stokpoisk
2. Слева вверху нажми на выпадающий список веток (там написано `main`) и выбери
   `claude/fitness-bot-training-nqnuoh`.
3. Зелёная кнопка **Code** → **Download ZIP**.
4. Распакуй архив и открой в нём папку `fitness_bot`.

### 1.2. Создай новый репозиторий

1. На GitHub справа вверху **+** → **New repository**.
2. **Repository name:** `fithelper-bot`.
3. Выбери **Private** (код не будет виден посторонним).
4. Галочки «Add a README» и прочие **не ставь**.
5. **Create repository**.

### 1.3. Загрузи файлы

1. На странице нового репозитория нажми ссылку **uploading an existing file**.
2. Перетащи в окно **содержимое** папки `fitness_bot` (не саму папку!):
   - `fitness_bot.py` — сам бот
   - `main.py` — запасная точка входа (если хостинг ждёт `main.py`)
   - `exercise_images.py` — промты и подписи для картинок упражнений
   - `requirements.txt` — список библиотек
   - `README.md`, `DEPLOY.md`, `IMAGE_PROMPTS.md` — документация
   - папки `images` и `tests`
3. Внизу нажми **Commit changes**.

**Не загружай** файл `.env`, папку `data` и файлы `*.db` — там токен и данные пользователей.

✅ Проверка: на главной странице репозитория сразу видны `fitness_bot.py` и `requirements.txt`
(не внутри какой-либо папки).

> **Если не хочешь отдельный репозиторий.** Можно деплоить и из `stokpoisk`, если BotHost позволяет
> указать главный файл в подпапке: главный файл `fitness_bot/fitness_bot.py`, ветка
> `claude/fitness-bot-training-nqnuoh`. Корневой `requirements.txt` от СтокПоиска содержит нужные
> библиотеки, но тянет и лишние (playwright и др.), поэтому установка будет дольше.

## Шаг 2. Настройка BotHost

### 2.1. Регистрация

Зарегистрируйся на bothost.ru и войди в личный кабинет.

### 2.2. Создай бота (проект)

1. Нажми создание нового бота / проекта.
2. **Платформа:** Telegram.
3. **Язык:** Python, **версия 3.11 или новее** (подойдут 3.11, 3.12, 3.13).
4. Если просят выбрать библиотеку — `python-telegram-bot` (или «другое / свой код»).

### 2.3. Подключи GitHub

1. Выбери способ загрузки кода **GitHub** и нажми подключение аккаунта.
2. GitHub попросит разрешить доступ — разреши (для приватного репозитория выбери
   **All repositories** или отметь `fithelper-bot`).
3. Выбери репозиторий `fithelper-bot` и ветку `main`.
4. Включи **автодеплой** (если есть такая галочка) — тогда после каждого изменения на GitHub
   бот сам обновится и перезапустится.

### 2.4. Главный файл и команды

| Поле | Значение |
|---|---|
| Главный файл / точка входа | `fitness_bot.py` (если поле требует `main.py` — укажи `main.py`, он тоже работает) |
| Команда установки (если спрашивают) | `pip install -r requirements.txt` |
| Команда запуска (если спрашивают) | `python fitness_bot.py` |

### 2.5. Переменные окружения

Найди раздел **Переменные окружения** (может называться **Variables**, **ENV**, **Настройки**)
и добавь:

| Имя | Значение | Обязательно |
|---|---|---|
| `FITNESS_BOT_TOKEN` | токен от @BotFather, например `7123456789:AAE...` | **да** |
| `ADMIN_ID` | твой Telegram ID от @userinfobot | желательно (админ-панель, загрузка фото, `/backup`) |
| `FITNESS_TZ` | `Europe/Moscow` (или свой часовой пояс) | нет |
| `FITNESS_DATA_DIR` | путь к постоянному диску, если BotHost его даёт (см. 2.6) | нет |

Правила: имя пишется **точно так, заглавными буквами**, без кавычек и пробелов вокруг значения.

> Если в BotHost есть отдельное поле «Токен бота» и он сам кладёт его в переменную `BOT_TOKEN` —
> это тоже сработает: бот читает и `FITNESS_BOT_TOKEN`, и `BOT_TOKEN`.

### 2.6. Где хранятся данные пользователей (важно!)

Анкеты, тренировки, рекорды и вес бот хранит в файле `data/fitness.db` рядом с ботом.
На некоторых хостингах файлы, созданные программой, **стираются при повторном деплое**.

1. Спроси поддержку BotHost: *«Сохраняются ли файлы, которые бот создаёт в своей папке `data/`,
   при перезапуске и при новом деплое из GitHub? Есть ли постоянный диск?»*
2. Если дают постоянный диск — впиши его путь в переменную `FITNESS_DATA_DIR`.
3. В любом случае делай резервные копии: отправь боту команду **`/backup`** — он пришлёт файл базы
   (работает только для `ADMIN_ID`). Удобно делать это перед каждым обновлением кода.

### 2.7. Запусти

1. Нажми **Запустить** / **Деплой**.
2. Открой **Логи**. Через 1–2 минуты (установка библиотек) должна появиться строка:
   ```
   Фитнес-бот запущен. Данные: .../data
   ```
3. Статус бота — «Работает» / «Running».

## Шаг 3. Проверь бота

1. Открой https://t.me/FitHelperTop_bot и нажми **Запустить** (`/start`).
2. Пройди анкету — бот пришлёт готовую программу и меню внизу экрана.
3. Нажми **🏋️ Тренировка на сегодня** → **▶️ Начать тренировку**, отправь подход, например `20 10`.
4. Отправь `/backup` — должен прийти файл базы (если задан `ADMIN_ID`).

## Шаг 4. Оформление бота в @BotFather

Отправь @BotFather команду `/mybots` → **FitHelperTop_bot** → **Edit Bot**:

**Edit Commands** — вставь список целиком (появится меню команд слева от поля ввода):
```
start - Начать и заполнить анкету
today - Тренировка на сегодня
program - Моя программа
progress - Прогресс и рекорды
weight - Вес тела
goals - Цели
cycle - Менструальный цикл
settings - Настройки
finish - Завершить тренировку
cancel - Отменить ввод
help - Как пользоваться
```

**Edit Description** (текст до нажатия «Запустить»):
```
Персональный фитнес-тренер в Telegram 💪
Готовая программа тренировок под твою цель, пол, возраст и опыт — даже если ты впервые в зале.
Покажу, какие мышцы тренируем, упражнения, подходы, повторы и стартовый вес, запишу результаты и подскажу, когда прибавлять нагрузку.
```

**Edit About** (короткий текст в профиле):
```
Готовая программа тренировок, дневник подходов и прогресс 💪
```

**Edit Botpic** — загрузи аватарку бота.

## Шаг 5. Как обновлять бота

- **Изменения в коде:** в репозитории `fithelper-bot` открой файл → значок карандаша → внеси правку →
  **Commit changes** (или **Add file → Upload files**, чтобы заменить файл новым). С автодеплоем
  BotHost сам перезапустит бота; без него — нажми **Перезапустить / Redeploy** в панели.
- **Картинки упражнений:** проще всего через самого бота — «🛠 Админ» → «🖼 Фото упражнений» →
  упражнение → кнопка кадра → отправь фото (нужен `ADMIN_ID`). Фото хранятся в Telegram, а в базе бота —
  только их идентификаторы, поэтому перед обновлением кода сделай `/backup`. Можно и через GitHub: папка
  `images` → **Add file → Upload files** → файлы с именами вроде `bench_1.png` → **Commit changes**.
- Перед обновлением сделай `/backup`, если не уверен, что данные сохраняются (см. 2.6).

## Частые проблемы

| Что видишь в логах / в Telegram | Причина и решение |
|---|---|
| `Не задан FITNESS_BOT_TOKEN` | Переменная не добавлена или имя с опечаткой. Проверь шаг 2.5 и перезапусти. |
| `InvalidToken` / `Unauthorized` | Неверный токен: лишний пробел, кавычки или токен был отозван. Скопируй заново из @BotFather. |
| `Конфликт: этот же бот уже запущен в другом месте` или `Conflict: terminated by other getUpdates request` | Бот запущен одновременно в двух местах (например, на компьютере и на BotHost). Останови лишний запуск — токен может работать только в одном месте. |
| `ModuleNotFoundError: No module named 'telegram'` | Не установились библиотеки: `requirements.txt` не в корне репозитория или не указана команда установки. |
| `SyntaxError` или ошибки про версию Python | Выбери Python 3.11 или новее. |
| `No such file` / не находит `fitness_bot.py` | Файлы загружены внутрь папки. В корне репозитория должны лежать сами файлы (шаг 1.3). |
| Бот молчит, ошибок нет | Проверь статус в панели (бот запущен?), не закончился ли тариф, правильный ли бот открыт в Telegram. |
| После обновления у пользователей пропали анкеты | Хостинг стёр файл базы при деплое. Нужен постоянный диск (шаг 2.6). Файл из `/backup` можно вернуть, загрузив его как `data/fitness.db` через файловый менеджер панели (если он есть) или попросив поддержку. |

Если что-то не получается — скопируй последние 20–30 строк из логов BotHost и пришли их.
