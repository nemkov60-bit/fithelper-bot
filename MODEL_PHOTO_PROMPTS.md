# Фото для приложения FitHelper

Все фото — **горизонтальные 16:10, 4K**, в одном стиле, чтобы приложение выглядело цельно:
тёмная современная студия или зал, мягкий свет с лёгким **лаймово-зелёным контровым светом** (цвет акцента
приложения #C8F04A), кинематографичная цветокоррекция. Поверх левой части фото ляжет текст, поэтому люди —
**в правой половине кадра**, слева — спокойный тёмный фон без деталей.

Загрузка: бот → «🛠 Админ» → «🖼 Фото для приложения» → выбрать место → «📤 Загрузить».
Лучше отправлять **файлом** (без сжатия), JPG/PNG/WEBP до 6 МБ. Промт для каждого места есть и в боте.

Общая концовка для всех промтов (уже добавлена в каждый):
> без текста, без логотипов и надписей на одежде, без водяных знаков, естественная анатомия, детализированная текстура кожи

## Советы
- Генерируйте 4–6 вариантов и выбирайте тот, где лица, руки и пальцы без искажений.
- Держите одну пару моделей во всех кадрах (если генератор умеет «референс персонажа») — так приложение выглядит
  как одна фотосессия.
- Проверьте, что слева достаточно тёмного «пустого» места — туда ляжет текст.
- Права: используйте генератор, где разрешено коммерческое использование, или собственную фотосессию с согласием моделей.
